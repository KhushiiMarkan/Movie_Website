# Movie Mingle 🎬

Movie Mingle is a movie ticket booking web application developed using Node.js, Express.js, EJS, HTML, CSS, and JavaScript.

## Features
- User Registration
- User Login
- Movie Dashboard
- Backend API Integration
- Error Handling Middleware
- Express Routing
- Responsive UI

## Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- HTML/CSS/JavaScript
